# CMD Sleep Disorders Center Website

This is a full stack website built for CMD Sleep clinic as a freelance commission. 
<br> It was created with:
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Resend**
- Hosted on **AWS LightSail**

## Features

- Clean, modern, and accessible design tailored for a medical website
- Responsive layout optimized for desktop and mobile devices
- In site email contact form to allow customers to email the clinic right from the website
